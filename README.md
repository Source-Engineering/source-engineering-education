# Source Engineering -- Education

> Curriculum and learning resources for the Source Engineering discipline.

This repository holds the discipline's educational surface. The curriculum is the discipline's growth path: a reader goes from "I have never heard of Source Engineering" to "I can ship a COTS-bearing system that passes the conformance suite" in a structured sequence of lessons. The "Source Engineering in 90 minutes" tutorial is the discipline's elevator pitch: a single guided session that produces a working artefact.

## What is in this repository

- `curriculum.md` -- the learning path. Five units, each with a name, a duration, an exit criterion, and a reading list.
- `tutorial-90-minutes.md` -- the 90-minute tutorial. A single guided session that produces a working COTS.
- `glossary.md` -- the student-friendly glossary. Cross-references the foundations repo's `terminology.md` and the practice repo's `glossary.md`.
- `learning-objectives.md` -- the discipline's learning objectives, by level (novice, practitioner, expert).

## How to engage

- **New to the discipline?** Start at `tutorial-90-minutes.md`. 90 minutes later, you will have produced and validated a COTS.
- **Adopting the discipline?** Read `curriculum.md` for the full learning path. The path is sequenced: do not skip the early units.
- **Teaching the discipline?** Use `learning-objectives.md` to design a course. The objectives are normative; the assignments are examples.

## Provenance

The curriculum is the discipline's growth path. It is derived from the foundations, the model, the specifications, the architecture, the conformance suite, the reference implementation, the tools, the practice, and the case studies. Every lesson in the curriculum is traceable to a discipline artefact.

## Status

This is the adoption slice (Phase 4). The curriculum, the 90-minute tutorial, the student glossary, and the learning objectives are seeded. The curriculum is the discipline's growth surface; new units are added as the discipline grows.
