# Changelog

All notable changes to the Source Engineering education repo are recorded here.

## 2026-10-11

### Added

- `curriculum.md` -- the curriculum. Five units: Foundations, Model, Specifications, Architecture, Demonstrate. Each unit has a question, a reading list, an assignment, and an exit criterion.
- `tutorial-90-minutes.md` -- the 90-minute tutorial. A single guided session that produces, validates, inspects, cites, and visualises a COTS.
- `learning-objectives.md` -- the discipline's learning objectives, by level (novice, practitioner, expert).
- `glossary.md` -- the student glossary. Student-friendly terms mapped to the discipline's canonical terms.
- `CHANGELOG.md` -- this file.

### Notes

- The curriculum is the discipline's growth path. The 90-minute tutorial is the first assignment in the first unit; the curriculum is the rest of the path.
- The learning objectives are normative. A course that does not address the objectives is not a Source Engineering course.
